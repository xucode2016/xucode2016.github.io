# 关于frpc启动失败的问题


## 问题描述  
在./frpc -c frpc.ini启动时，systemctl status frpc报错, <br/>
查看frpc日志： frpc会将日志输出到系统的日志文件中，可以通过以下命令查看frpc的日志：<br/>
```
sudo tail -f /var/log/syslog | grep frpc
这将实时显示最新的frpc日志信息。如果需要查看更多的日志信息，可以通过cat或者less命令查看/var/log/syslog文件。
```
得到相关log<br/>
```
custom_domains and subdomain should set at least one of them Jan 11 09:42:33 raspberrypi systemd[1]: frpc.service: Main process exited, code=exited, status=1/FAILURE Jan 11 09:42:33 raspberrypi systemd[1]: frpc.service: Failed with result 'exit-code'.
```
https://github.com/fatedier/frp/issues/4128<br/>
通过这个issue和试验得知,当 frpc的type配置为http时 必须有custom_domain，所以如果不需要type=http时，改成type=tcp即可
